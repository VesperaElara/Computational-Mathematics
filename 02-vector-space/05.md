# Comprehensive Lecture Notes: Basis of a Vector Space

## 1. Introduction to Basis
In linear algebra, a **basis** serves as a minimal, essential coordinate system for a vector space. It acts as a structural "skeleton" or set of building blocks: every single vector within the space can be uniquely constructed from the vectors in the basis, without containing any redundant or unnecessary elements.

---

## 2. Formal Definition of a Basis
Let $V$ be a vector space over a field $F$ (such as the real numbers $\mathbb{R}$). A subset $S \subseteq V$ is called a **basis** of $V$ if and only if it satisfies two fundamental properties:

1. **Linear Independence:** The set $S$ consists of linearly independent vectors. That is, no vector in $S$ can be expressed as a linear combination of the other vectors in $S$. For any finite collection of vectors $v_1, v_2, \dots, v_k \in S$:
   $$ \alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_k v_k = \mathbf{0} \implies \alpha_1 = \alpha_2 = \dots = \alpha_k = 0 $$

2. **Spanning Property:** The set $S$ spans the entire vector space $V$. That is, the linear span of $S$, denoted $L(S)$, is equal to $V$:
   $$ L(S) = V $$
   This means for every vector $v \in V$, there exist scalars $\alpha_1, \alpha_2, \dots, \alpha_k$ and vectors $s_1, s_2, \dots, s_k \in S$ such that:
   $$ v = \alpha_1 s_1 + \alpha_2 s_2 + \dots + \alpha_k s_k $$

## 3. Equivalent Characterizations of a Basis
A subset $B \subseteq V$ is a basis if and only if it satisfies any one of the following three equivalent structural properties:

### Characterization 1: Minimal Generating Set
$B$ is a **minimal generating set** (or minimal spanning set) of $V$. 
* **Meaning:** $B$ spans $V$ ($L(B) = V$), but if you remove even a single vector from $B$, the remaining subset will no longer span $V$. No proper subset of $B$ can generate $V$.

### Characterization 2: Maximal Linearly Independent Set
$B$ is a **maximal linearly independent set** in $V$.
* **Meaning:** $B$ is linearly independent, but if you add any other vector $v \in V$ ($v \notin B$) to $B$, the resulting expanded set $B \cup \{v\}$ automatically becomes linearly dependent.

### Characterization 3: Unique Representation Property
Every vector $v \in V$ can be expressed as a linear combination of vectors in $B$ in a **strictly unique way**.
* **Meaning:** If $v = \sum \alpha_i b_i$ and $v = \sum \beta_i b_i$ for $b_i \in B$, then $\alpha_i = \beta_i$ for all $i$.

## 4. Standard (Canonical) Basis of $\mathbb{R}^n$
The **standard basis** (also known as the natural or canonical basis) of the $n$-dimensional Euclidean space $\mathbb{R}^n$ consists of $n$ unit vectors:
$$ \{e_1, e_2, \dots, e_n\} $$
where each $e_i$ is a vector with $1$ in the $i^{\text{th}}$ component and $0$ in all other components:
$$ e_1 = (1, 0, 0, \dots, 0) $$
$$ e_2 = (0, 1, 0, \dots, 0) $$
$$ \vdots $$
$$ e_n = (0, 0, 0, \dots, 1) $$

### Complete Proof: $\{e_1, e_2, \dots, e_n\}$ is a Basis for $\mathbb{R}^n$

#### Step 1: Proof of Linear Independence
Consider the zero vector equation with scalars $\alpha_1, \alpha_2, \dots, \alpha_n \in \mathbb{R}$:
$$ \alpha_1 e_1 + \alpha_2 e_2 + \dots + \alpha_n e_n = \mathbf{0} $$

Substitute the explicit coordinate definitions of $e_i$:
$$ \alpha_1 (1, 0, \dots, 0) + \alpha_2 (0, 1, \dots, 0) + \dots + \alpha_n (0, 0, \dots, 1) = (0, 0, \dots, 0) $$

Perform scalar multiplication across each component:
$$ (\alpha_1, 0, \dots, 0) + (0, \alpha_2, \dots, 0) + \dots + (0, 0, \dots, \alpha_n) = (0, 0, \dots, 0) $$

Perform vector addition by adding corresponding components:
$$ (\alpha_1, \alpha_2, \dots, \alpha_n) = (0, 0, \dots, 0) $$

By the definition of vector equality, component-wise comparison yields:
$$ \alpha_1 = 0, \quad \alpha_2 = 0, \quad \dots, \quad \alpha_n = 0 $$

Since the only solution is the trivial solution ($\alpha_i = 0$ for all $i$), the set $\{e_1, e_2, \dots, e_n\}$ is **linearly independent**.

#### Step 2: Proof of Spanning Property
Let $\mathbf{x} = (x_1, x_2, \dots, x_n)$ be an arbitrary vector in $\mathbb{R}^n$.

We can decompose $\mathbf{x}$ as:
$$ (x_1, x_2, \dots, x_n) = (x_1, 0, \dots, 0) + (0, x_2, \dots, 0) + \dots + (0, 0, \dots, x_n) $$

Factoring out the individual components as scalars:
$$ \mathbf{x} = x_1 (1, 0, \dots, 0) + x_2 (0, 1, \dots, 0) + \dots + x_n (0, 0, \dots, 1) $$
$$ \mathbf{x} = x_1 e_1 + x_2 e_2 + \dots + x_n e_n $$

Since any arbitrary vector $\mathbf{x} \in \mathbb{R}^n$ can be expressed as a linear combination of $\{e_1, e_2, \dots, e_n\}$, the set **spans $\mathbb{R}^n$**.

#### Conclusion
Because $\{e_1, e_2, \dots, e_n\}$ is both linearly independent and spans $\mathbb{R}^n$, it constitutes a **basis** for $\mathbb{R}^n$.

## 5. Worked Examples & Exercises

### Example 1: Standard Basis of $\mathbb{R}^2$
In $\mathbb{R}^2$, the space of all coordinate pairs $(a, b)$ where $a, b \in \mathbb{R}$, the standard basis consists of $e_1 = (1, 0)$ and $e_2 = (0, 1)$.

Any arbitrary vector $v = (a, b)$ can be uniquely written as:
$$ v = a(1, 0) + b(0, 1) = a e_1 + b e_2 $$

---

### Example 2: Non-Standard Basis Verification for $\mathbb{R}^2$
**Problem:** Prove that the set of vectors $S = \{v_1, v_2\} = \{(1, 1), (-1, 2)\}$ forms a basis for $\mathbb{R}^2$.

#### Part (i): Verification of Linear Independence
Assume there exist scalars $a, b \in \mathbb{R}$ such that:
$$ a(1, 1) + b(-1, 2) = (0, 0) $$

Distribute the scalars into the vectors:
$$ (a, a) + (-b, 2b) = (0, 0) $$

Combine into a single vector equation:
$$ (a - b, a + 2b) = (0, 0) $$

Equating corresponding components produces a system of two homogeneous linear equations:
1. $a - b = 0 \implies a = b$
2. $a + 2b = 0$

Substitute equation (1) into equation (2):
$$ b + 2b = 0 \implies 3b = 0 \implies b = 0 $$

Since $a = b$, it follows that $a = 0$.

Because $a = 0$ and $b = 0$ is the unique solution, the set $\{(1, 1), (-1, 2)\}$ is **linearly independent**.

#### Part (ii): Verification of the Spanning Property
Let $(a, b)$ be an arbitrary target vector in $\mathbb{R}^2$. We must show that there exist scalar coefficients $x, y \in \mathbb{R}$ such that:
$$ x(1, 1) + y(-1, 2) = (a, b) $$

Expand and group components:
$$ (x - y, x + 2y) = (a, b) $$

Set up the system of linear equations:
1. $x - y = a$
2. $x + 2y = b$

To solve for $x$ and $y$, subtract equation (1) from equation (2):
$$ (x + 2y) - (x - y) = b - a $$
$$ 3y = b - a \implies y = \frac{b - a}{3} $$

Substitute the expression for $y$ back into equation (1) to solve for $x$:
$$ x - \left(\frac{b - a}{3}\right) = a $$
$$ x = a + \frac{b - a}{3} = \frac{3a + b - a}{3} = \frac{2a + b}{3} $$

Since explicit scalar solutions $x = \frac{2a + b}{3}$ and $y = \frac{b - a}{3}$ exist for any arbitrary $(a, b) \in \mathbb{R}^2$, the set $\{(1, 1), (-1, 2)\}$ **spans $\mathbb{R}^2$**.

#### Conclusion
Since $S = \{(1, 1), (-1, 2)\}$ satisfies both linear independence and the spanning property, it is a valid **basis for $\mathbb{R}^2$**.

### Important Observations & Shortcuts
1. **Geometric Inspection for 2D Vectors:** Two vectors in $\mathbb{R}^2$ are linearly independent if and only if neither vector is a scalar multiple of the other (i.e., they are non-parallel and non-zero). Since $(-1, 2)$ is clearly not a multiple of $(1, 1)$, independence can be established by inspection.
2. **Dimension Shortcut:** The dimension of $\mathbb{R}^2$ is $2$. A known theorem in linear algebra states that if a set contains exactly $n$ vectors in an $n$-dimensional vector space, verifying *either* linear independence *or* the spanning property is sufficient to prove it is a basis.
