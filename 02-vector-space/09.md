# Linear Independence: Solved Problems, Theorems, and Basis Verification

## 1. Solved Problems: Testing Linear Independence

To test whether a set of vectors $\{v_1, v_2, \dots, v_k\}$ in $\mathbb{R}^n$ is linearly independent, we form the linear combination equation:
$$\lambda_1 v_1 + \lambda_2 v_2 + \dots + \lambda_k v_k = \mathbf{0}$$

This leads to a system of homogeneous equations $A \boldsymbol{\lambda} = \mathbf{0}$. For $n$ vectors in $\mathbb{R}^n$, we can directly evaluate the determinant of the coefficient matrix $A$:
* If $\det(A) \neq 0$, the vectors are **linearly independent**.
* If $\det(A) = 0$, the vectors are **linearly dependent**.

---

### Problem 1
**Verify whether or not the set of vectors $S = \{(4, 2, -1), (3, -6, -5)\}$ in $\mathbb{R}^3$ is linearly independent.**

#### Solution
Consider the vector equation:
$$\lambda_1 (4, 2, -1) + \lambda_2 (3, -6, -5) = (0, 0, 0)$$

This expands to the system of equations:
$$4\lambda_1 + 3\lambda_2 = 0$$
$$2\lambda_1 - 6\lambda_2 = 0$$
$$-\lambda_1 - 5\lambda_2 = 0$$

From equation (2), $2\lambda_1 = 6\lambda_2 \implies \lambda_1 = 3\lambda_2$.  
Substituting $\lambda_1 = 3\lambda_2$ into equation (1):
$$4(3\lambda_2) + 3\lambda_2 = 0 \implies 15\lambda_2 = 0 \implies \lambda_2 = 0$$

Since $\lambda_2 = 0$, then $\lambda_1 = 3(0) = 0$.

Because $\lambda_1 = \lambda_2 = 0$ is the **only** solution, the set of vectors is **linearly independent**.

---

### Problem 2
**Verify whether or not the set of vectors $S = \{(1, 1, 1), (0, 2, 3), (1, -2, 3)\}$ in $\mathbb{R}^3$ is linearly independent.**

#### Solution
Form the matrix $A$ placing the given vectors as rows:
$$A = \begin{bmatrix} 1 & 1 & 1 \\ 0 & 2 & 3 \\ 1 & -2 & 3 \end{bmatrix}$$

Calculate the determinant $|A|$ by expanding along Row 1:
$$|A| = 1 \begin{vmatrix} 2 & 3 \\ -2 & 3 \end{vmatrix} - 1 \begin{vmatrix} 0 & 3 \\ 1 & 3 \end{vmatrix} + 1 \begin{vmatrix} 0 & 2 \\ 1 & -2 \end{vmatrix}$$

$$|A| = 1 \big((2)(3) - (3)(-2)\big) - 1 \big((0)(3) - (3)(1)\big) + 1 \big((0)(-2) - (2)(1)\big)$$
$$|A| = 1 (6 + 6) - 1 (0 - 3) + 1 (0 - 2)$$
$$|A| = 12 + 3 - 2 = 13$$

Since $|A| = 13 \neq 0$, the set of vectors is **linearly independent**.

---

### Problem 3
**Verify whether or not the set of vectors $S = \{(1, 2, 3), (1, 1, 1), (1, 0, 1)\}$ in $\mathbb{R}^3$ is linearly independent.**

#### Solution
Form the coefficient matrix $A$:
$$A = \begin{bmatrix} 1 & 2 & 3 \\ 1 & 1 & 1 \\ 1 & 0 & 1 \end{bmatrix}$$

Calculate $|A|$ by expanding along Row 3 (simplest due to the zero entry):
$$|A| = 1 \begin{vmatrix} 2 & 3 \\ 1 & 1 \end{vmatrix} - 0 \begin{vmatrix} 1 & 3 \\ 1 & 1 \end{vmatrix} + 1 \begin{vmatrix} 1 & 2 \\ 1 & 1 \end{vmatrix}$$

$$|A| = 1 \big((2)(1) - (3)(1)\big) - 0 + 1 \big((1)(1) - (2)(1)\big)$$
$$|A| = 1 (2 - 3) + 1 (1 - 2) = -1 - 1 = -2$$

Since $|A| = -2 \neq 0$, the set of vectors is **linearly independent**.

---

### Problem 4
**Verify whether or not the set of vectors $S = \{(1, 3, -2), (2, -1, 4), (1, -11, 14)\}$ in $\mathbb{R}^3$ is linearly independent.**

#### Solution
Form the coefficient matrix $A$:
$$A = \begin{bmatrix} 1 & 3 & -2 \\ 2 & -1 & 4 \\ 1 & -11 & 14 \end{bmatrix}$$

Calculate $|A|$ by expanding along Row 1:
$$|A| = 1 \begin{vmatrix} -1 & 4 \\ -11 & 14 \end{vmatrix} - 3 \begin{vmatrix} 2 & 4 \\ 1 & 14 \end{vmatrix} + (-2) \begin{vmatrix} 2 & -1 \\ 1 & -11 \end{vmatrix}$$

$$|A| = 1 \big((-1)(14) - (4)(-11)\big) - 3 \big((2)(14) - (4)(1)\big) - 2 \big((2)(-11) - (-1)(1)\big)$$
$$|A| = 1 (-14 + 44) - 3 (28 - 4) - 2 (-22 + 1)$$
$$|A| = 1 (30) - 3 (24) - 2 (-21)$$
$$|A| = 30 - 72 + 42 = 0$$

Since $|A| = 0$, non-trivial solutions exist for $\boldsymbol{\lambda}$. Thus, the set of vectors is **not linearly independent** (it is **linearly dependent**).

## 2. Fundamental Hereditary Theorems

### Theorem 1: Inheritance of Independence by Subsets
> If a set $S$ of vectors is linearly independent, then every subset of $S$ is also linearly independent.

#### Proof
Let $S = \{a_1, a_2, \dots, a_r\}$ be a linearly independent set of vectors in a vector space $V$. 

By definition of linear independence, the vector equation:
$$\lambda_1 a_1 + \lambda_2 a_2 + \dots + \lambda_r a_r = \mathbf{0}$$
forces $\lambda_1 = \lambda_2 = \dots = \lambda_r = 0$.

Now, let $T$ be an arbitrary non-empty subset of $S$. Without loss of generality, reorder the vectors so that $T = \{a_1, a_2, \dots, a_k\}$ where $k \le r$.

To test $T$ for linear independence, consider the relation:
$$\mu_1 a_1 + \mu_2 a_2 + \dots + \mu_k a_k = \mathbf{0}$$

We can extend this equation to the full set $S$ by adding the remaining vectors with zero coefficients:
$$\mu_1 a_1 + \mu_2 a_2 + \dots + \mu_k a_k + 0 \cdot a_{k+1} + \dots + 0 \cdot a_r = \mathbf{0}$$

Because the original set $S = \{a_1, a_2, \dots, a_r\}$ is linearly independent, **all** scalar coefficients in this linear combination must equal zero:
$$\mu_1 = 0, \, \mu_2 = 0, \, \dots, \, \mu_k = 0$$

Therefore, the equation $\mu_1 a_1 + \dots + \mu_k a_k = \mathbf{0}$ yields only the trivial solution. This proves that the subset $T$ is **linearly independent**. $\blacksquare$

---

### Theorem 2: Inheritance of Dependence by Supersets
> If a set $S$ of vectors is linearly dependent, then every superset of $S$ is also linearly dependent.

#### Proof
Let $S = \{a_1, a_2, \dots, a_k\}$ be a linearly dependent set in $V$.

By definition, there exist scalars $\lambda_1, \lambda_2, \dots, \lambda_k$, **not all zero**, such that:
$$\lambda_1 a_1 + \lambda_2 a_2 + \dots + \lambda_k a_k = \mathbf{0}$$

Let $W$ be any superset of $S$. Let $W = \{a_1, a_2, \dots, a_k, a_{k+1}, \dots, a_r\}$ where $r > k$.

To check $W$ for linear dependence, form the equation:
$$c_1 a_1 + c_2 a_2 + \dots + c_k a_k + c_{k+1} a_{k+1} + \dots + c_r a_r = \mathbf{0}$$

Choose the coefficients as follows:
* Set $c_i = \lambda_i$ for $1 \le i \le k$.
* Set $c_j = 0$ for $k+1 \le j \le r$.

Substituting these coefficients into the linear combination:
$$\lambda_1 a_1 + \lambda_2 a_2 + \dots + \lambda_k a_k + 0 \cdot a_{k+1} + \dots + 0 \cdot a_r = \mathbf{0} + \mathbf{0} = \mathbf{0}$$

Since at least one $\lambda_i \neq 0$ (from the linear dependence of $S$), at least one coefficient $c_i \neq 0$ in this sum for $W$.

Therefore, the set $W$ has a non-trivial solution and is **linearly dependent**. $\blacksquare$

## 3. Comprehensive Solutions to Exercises

### Exercise 1: Testing Linear Independence

#### Part (i)
**Test whether $S = \{(2, 2, 3), (-1, -2, 1), (0, 1, 0)\}$ is linearly independent.**

*Solution:*  
Form matrix $A$ and calculate its determinant:
$$A = \begin{bmatrix} 2 & 2 & 3 \\ -1 & -2 & 1 \\ 0 & 1 & 0 \end{bmatrix}$$

Expand $|A|$ along Row 3:
$$|A| = -0 \begin{vmatrix} 2 & 3 \\ -2 & 1 \end{vmatrix} + 1 \begin{vmatrix} 2 & 3 \\ -1 & 1 \end{vmatrix} - 0 \begin{vmatrix} 2 & 2 \\ -1 & -2 \end{vmatrix}$$
$$|A| = 1 \big((2)(1) - (3)(-1)\big) = 1(2 + 3) = 5$$

Since $|A| = 5 \neq 0$, the set is **linearly independent**.

---

#### Part (ii)
**Test whether $S = \{(4, 2, 1), (2, -6, -5)\}$ is linearly independent.**

*Solution:*  
Set up the linear combination:
$$\lambda_1 (4, 2, 1) + \lambda_2 (2, -6, -5) = (0, 0, 0)$$

Equating components:
1. $4\lambda_1 + 2\lambda_2 = 0 \implies \lambda_2 = -2\lambda_1$
2. $2\lambda_1 - 6\lambda_2 = 0$
3. $\lambda_1 - 5\lambda_2 = 0$

Substitute $\lambda_2 = -2\lambda_1$ into component 3:
$$\lambda_1 - 5(-2\lambda_1) = 0 \implies 11\lambda_1 = 0 \implies \lambda_1 = 0$$
Then $\lambda_2 = -2(0) = 0$.

Since $\lambda_1 = \lambda_2 = 0$ is the only solution, the set is **linearly independent**.

---

#### Part (iii)
**Test whether $S = \{(4, 2, 1), (2, -6, -5), (1, -2, 3), (1, -1, 2)\}$ is linearly independent.**

*Solution:*  
The set $S$ contains $k = 4$ vectors in the $n = 3$ dimensional space $E^3$ ($\mathbb{R}^3$).

By the **Maximum Capacity Theorem**, the maximum number of linearly independent vectors in $\mathbb{R}^n$ is $n$. Any set of $n + 1$ or more vectors in $\mathbb{R}^n$ is automatically linearly dependent.

Since $4 > 3$, the set is **linearly dependent** (not linearly independent).

### Exercise 3: Basis Testing and Basis Coordinate Representation

A set $S$ forms a **basis** for $E^3$ ($\mathbb{R}^3$) if and only if it satisfies two conditions:
1. $S$ contains exactly $\dim(E^3) = 3$ vectors.
2. $S$ is linearly independent (evaluated via $\det(A) \neq 0$).

---

#### Step 1: Evaluating Basis Candidates

* **Set (i): $S_1 = \{(2, 2, 3), (-1, -2, 1), (0, 1, 0)\}$**  
  * Number of vectors = 3.  
  * Determinant $|A| = 5 \neq 0$ (from Exercise 1.i).  
  * **Result:** $S_1$ **forms a basis** for $E^3$.

* **Set (ii): $S_2 = \{(4, 2, 1), (2, -6, -5)\}$**  
  * Number of vectors = 2.  
  * Since $\dim(E^3) = 3$, 2 vectors cannot span $E^3$.  
  * **Result:** $S_2$ **does NOT form a basis** for $E^3$.

* **Set (iii): $S_3 = \{(4, 2, 1), (2, -6, -5), (1, -2, 3), (1, -1, 2)\}$**  
  * Number of vectors = 4.  
  * Any set with more than 3 vectors in $E^3$ is linearly dependent.  
  * **Result:** $S_3$ **does NOT form a basis** for $E^3$.

---

#### Step 2: Expressing $(3, 1, 2)$ as a Linear Combination of the Basis Vectors

Since $S_1 = \{v_1, v_2, v_3\} = \{(2, 2, 3), (-1, -2, 1), (0, 1, 0)\}$ is the only valid basis, we find unique scalars $c_1, c_2, c_3$ such that:
$$(3, 1, 2) = c_1 (2, 2, 3) + c_2 (-1, -2, 1) + c_3 (0, 1, 0)$$

![Diagram: Geometric Vector Decomposition in R^3 Basis](./images/basis_decomposition_r3.png)
*Detailed Layout Description:* The visual shows a 3D coordinate system representing $E^3$. Three non-coplanar basis vectors $v_1=(2,2,3)$, $v_2=(-1,-2,1)$, and $v_3=(0,1,0)$ originate from $(0,0,0)$. Parallelepiped construction lines extend along the directions of these vectors to meet at the target vector $\mathbf{v} = (3,1,2)$, visually demonstrating how $\mathbf{v}$ decomposes into a unique linear combination $c_1 v_1 + c_2 v_2 + c_3 v_3$.

Equating components:
$$2c_1 - c_2 + 0c_3 = 3 \quad \implies \quad 2c_1 - c_2 = 3$$
$$2c_1 - 2c_2 + c_3 = 1$$
$$3c_1 + c_2 + 0c_3 = 2 \quad \implies \quad 3c_1 + c_2 = 2$$

##### Solving the System
Add equation (1) and equation (3):
$$(2c_1 - c_2) + (3c_1 + c_2) = 3 + 2$$
$$5c_1 = 5 \implies c_1 = 1$$

Substitute $c_1 = 1$ into equation (3):
$$3(1) + c_2 = 2 \implies c_2 = 2 - 3 = -1$$

Substitute $c_1 = 1$ and $c_2 = -1$ into equation (2):
$$2(1) - 2(-1) + c_3 = 1$$
$$2 + 2 + c_3 = 1 \implies 4 + c_3 = 1 \implies c_3 = -3$$

##### Final Representation
The vector $(3, 1, 2)$ expressed as a linear combination of the basis vectors is:
$$(3, 1, 2) = 1(2, 2, 3) - 1(-1, -2, 1) - 3(0, 1, 0)$$
