## 1. Properties of the Linear Span

The operator $L(S)$ (or $\text{Span}(S)$) converts any arbitrary set of vectors $S \subseteq V$ into a complete vector subspace by collecting all possible finite linear combinations of vectors in $S$. Below are three fundamental structural properties that govern how spans behave under set inclusion, union, and nested operations.

```
              +-----------------------------------+
              |         Vector Space V            |
              |                                   |
              |      +---------------------+      |
              |      | Subset S            |      |
              |      +----------+----------+      |
              |                 |                 |
              |                 v                 |
              |      +---------------------+      |
              |      | Subspace L(S)       |      |
              |      +----------+----------+      |
              |                 |                 |
              |                 v                 |
              |      +---------------------+      |
              |      | Subspace L(L(S))    |      |
              |      |   (No Expansion)    |      |
              |      +---------------------+      |
              +-----------------------------------+

```

*Visual representation of the span operator's idempotency: Taking the span of an already spanned set $L(S)$ yields no new vectors because $L(S)$ is already closed under all linear combinations.*

### Property (i): Monotonicity / Preservation of Inclusion

> **Theorem:** If $S \subseteq T \subseteq V$, then $L(S) \subseteq L(T)$.

#### Intuition & Meaning
If a set $T$ contains all vectors of set $S$ plus some extra vectors, then any linear combination that can be built using vectors from $S$ can automatically be built using vectors from $T$ (by assigning scalar coefficients of zero to the extra vectors in $T$).

#### Complete Proof
1. Let $v \in L(S)$. By definition of the linear span, $v$ can be written as a finite linear combination of vectors in $S$:
   $$v = \alpha_1 s_1 + \alpha_2 s_2 + \dots + \alpha_n s_n = \sum_{i=1}^{n} \alpha_i s_i$$
   where $s_i \in S$ and $\alpha_i \in F$ for $1 \le i \le n$.
2. Because $S \subseteq T$, every element $s_i \in S$ is also an element of $T$ ($s_i \in T$ for all $1 \le i \le n$).
3. Thus, the sum $v = \sum_{i=1}^{n} \alpha_i s_i$ is a valid finite linear combination of elements belonging to $T$.
4. By definition of $L(T)$, $v \in L(T)$.
5. Since every $v \in L(S)$ belongs to $L(T)$, $L(S) \subseteq L(T)$. $\blacksquare$

---

### Property (ii): Span of a Union

> **Theorem:** For any two subsets $S, T \subseteq V$, $L(S \cup T) = L(S) + L(T)$.

*Note on Notation:* The **sum of two subspaces** $W_1 + W_2$ is defined as $\{w_1 + w_2 \mid w_1 \in W_1, w_2 \in W_2\}$.

#### Intuition & Meaning
Taking all linear combinations of vectors from the combined set $S \cup T$ is mathematically equivalent to taking a vector built from $S$, taking a vector built from $T$, and adding them together.

#### Complete Proof
To prove set equality $A = B$, we must show both inclusions: $A \subseteq B$ and $B \subseteq A$.

**Part A: Prove $L(S \cup T) \subseteq L(S) + L(T)$**
1. Let $u \in L(S \cup T)$. By definition, $u$ is a finite linear combination of elements in $S \cup T$:
   $$u = \sum_{i=1}^{n} \alpha_i s_i + \sum_{j=1}^{m} \beta_j t_j$$
   where $s_i \in S$, $t_j \in T$, and $\alpha_i, \beta_j \in F$.
2. Notice that $v = \sum_{i=1}^{n} \alpha_i s_i \in L(S)$ and $w = \sum_{j=1}^{m} \beta_j t_j \in L(T)$.
3. Therefore, $u = v + w$ where $v \in L(S)$ and $w \in L(T)$.
4. By definition of the sum of subspaces, $u \in L(S) + L(T)$.

**Part B: Prove $L(S) + L(T) \subseteq L(S \cup T)$**
1. Let $x \in L(S) + L(T)$. Then $x = v + w$ for some $v \in L(S)$ and $w \in L(T)$.
2. Since $S \subseteq (S \cup T)$, Property (i) implies $L(S) \subseteq L(S \cup T)$. Hence $v \in L(S \cup T)$.
3. Since $T \subseteq (S \cup T)$, Property (i) implies $L(T) \subseteq L(S \cup T)$. Hence $w \in L(S \cup T)$.
4. Since $L(S \cup T)$ is a subspace, it is closed under vector addition. Thus $v + w = x \in L(S \cup T)$.

Combining **Part A** and **Part B** gives $L(S \cup T) = L(S) + L(T)$. $\blacksquare$

---

### Property (iii): Idempotency of the Span Operator

> **Theorem:** For any subset $S \subseteq V$, $L(L(S)) = L(S)$.

#### Intuition & Meaning
The span operator is **idempotent** (applying it a second time produces no new vectors). Once you construct $L(S)$, you already have a full subspace containing every possible linear combination. Taking linear combinations of elements that are already linear combinations does not generate any new space.

#### Complete Proof
**Part A: Prove $L(S) \subseteq L(L(S))$**
1. From our prior theorem on linear spans, we know that for any set $A \subseteq V$, $A \subseteq L(A)$.
2. Substituting $A = L(S)$ directly yields $L(S) \subseteq L(L(S))$.

**Part B: Prove $L(L(S)) \subseteq L(S)$**
1. We know from earlier results that $L(S)$ is a subspace of $V$.
2. By definition of a subspace, $L(S)$ is closed under all vector additions and scalar multiplications.
3. Therefore, any finite linear combination of vectors chosen from $L(S)$ must remain inside $L(S)$.
4. Since $L(L(S))$ consists of all finite linear combinations of vectors in $L(S)$, every element of $L(L(S))$ must lie in $L(S)$.
5. Hence, $L(L(S)) \subseteq L(S)$.

Combining **Part A** and **Part B** proves $L(L(S)) = L(S)$. $\blacksquare$

## 2. Finite-Dimensional Vector Spaces

### 2.1 Formal Definition

> **Definition (Finite-Dimensional Vector Space):** A vector space $V$ over a field $F$ is said to be **finite-dimensional** if there exists a **finite** subset $S = \{v_1, v_2, \dots, v_n\} \subseteq V$ such that:
> 
> $$L(S) = V$$
> 
> In this case, we say that the finite set $S$ **spans** or **generates** the vector space $V$. If no such finite set exists, $V$ is called **infinite-dimensional**.

---

### 2.2 Concrete Example: Proving $\mathbb{R}^2$ is Finite-Dimensional
**Problem:** Show that $V = \mathbb{R}^2$ over the field $\mathbb{R}$ is finite-dimensional using the set $S = \{(1,0), (1,1), (0,1)\}$.

```
                        Y-axis
                          ^
                          |      (1,1)
                          |     *
                   (0,1)  |   / |
                     *----+--/--+---> X-axis
                     |    | /   |
                     |    +-----+
                     |   (0,0)  (1,0)

```

![Diagram: Vectors in S spanning the entire R2 plane](./images/r2_spanning_set.png)
*Vectors $(1,0)$, $(1,1)$, and $(0,1)$ in $\mathbb{R}^2$. Any target vector $(x,y)$ in the Cartesian plane can be generated by a linear combination of these three vectors.*

**Step-by-Step Proof:**
1. Consider the subset $S = \{v_1, v_2, v_3\} \subseteq \mathbb{R}^2$ where $v_1 = (1,0)$, $v_2 = (1,1)$, $v_3 = (0,1)$.
2. The linear span $L(S)$ is given by:
   $$L(S) = \{ \alpha_1(1,0) + \alpha_2(1,1) + \alpha_3(0,1) \mid \alpha_1, \alpha_2, \alpha_3 \in \mathbb{R} \}$$
3. Perform vector additions and scalar multiplications component-wise:
   $$\alpha_1(1,0) + \alpha_2(1,1) + \alpha_3(0,1) = (\alpha_1, 0) + (\alpha_2, \alpha_2) + (0, \alpha_3) = (\alpha_1 + \alpha_2, \; \alpha_2 + \alpha_3)$$
   Thus:
   $$L(S) = \{ (\alpha_1 + \alpha_2, \; \alpha_2 + \alpha_3) \mid \alpha_1, \alpha_2, \alpha_3 \in \mathbb{R} \}$$
4. Since any component-wise sum of real numbers yields a real vector in $\mathbb{R}^2$, clearly $L(S) \subseteq \mathbb{R}^2$.
5. Now, choose an arbitrary target vector $(x, y) \in \mathbb{R}^2$. We must show that there exist scalars $\alpha_1, \alpha_2, \alpha_3 \in \mathbb{R}$ such that:
   $$(x, y) = (\alpha_1 + \alpha_2, \; \alpha_2 + \alpha_3)$$
6. Select $\alpha_1 = x$, $\alpha_2 = 0$, and $\alpha_3 = y$.
   Substituting these values into the expression:
   $$(\alpha_1 + \alpha_2, \; \alpha_2 + \alpha_3) = (x + 0, \; 0 + y) = (x, y)$$
7. Since every arbitrary vector $(x,y) \in \mathbb{R}^2$ can be written in this form, $\mathbb{R}^2 \subseteq L(S)$.
8. Therefore, $L(S) = \mathbb{R}^2$. Because $S$ contains a finite number of elements ($|S| = 3$), $V = \mathbb{R}^2$ is a **finite-dimensional vector space**. $\blacksquare$

## 3. Linear Dependence and Linear Independence

### 3.1 Core Definitions

> **Definition (Linear Dependence):** A finite set of vectors $\{v_1, v_2, \dots, v_n\}$ in a vector space $V$ over $F$ is **linearly dependent** if there exist scalars $a_1, a_2, \dots, a_n \in F$, **not all equal to zero** (i.e., at least one $a_i \neq 0$), such that:
> 
> $$a_1 v_1 + a_2 v_2 + \dots + a_n v_n = \mathbf{0}$$

> **Definition (Linear Independence):** A finite set of vectors $\{v_1, v_2, \dots, v_n\}$ in $V$ is **linearly independent** if it is *not* linearly dependent.
> 
> Equivalent Operational Criterion: $\{v_1, v_2, \dots, v_n\}$ is linearly independent if the **only** scalar solution to the zero-combination equation:
> 
> $$a_1 v_1 + a_2 v_2 + \dots + a_n v_n = \mathbf{0}$$
> 
> is the trivial solution:
> 
> $$a_1 = a_2 = \dots = a_n = 0$$

---

### 3.2 Concrete Examples

#### Example 1: Demonstrating Linear Dependence in $\mathbb{R}^2$
Let $v_1 = (1,0)$, $v_2 = (2,2)$, $v_3 = (0,1)$, $v_4 = (3,3) \in \mathbb{R}^2$.
We set up the vector equation:
$$\alpha_1 v_1 + \alpha_2 v_2 + \alpha_3 v_3 + \alpha_4 v_4 = \mathbf{0} = (0,0)$$

Substitute the vectors:
$$\alpha_1 (1,0) + \alpha_2 (2,2) + \alpha_3 (0,1) + \alpha_4 (3,3) = (0,0)$$

Choose the scalars:
$$\alpha_1 = 2, \quad \alpha_2 = -1, \quad \alpha_3 = 2, \quad \alpha_4 = 0$$

Verify the linear combination:
$$2(1,0) + (-1)(2,2) + 2(0,1) + 0(3,3) = (2,0) + (-2,-2) + (0,2) + (0,0) = (0,0)$$

Because we found a set of scalars $(\alpha_1, \alpha_2, \alpha_3, \alpha_4) = (2, -1, 2, 0)$ where **not all scalars are zero**, the set $\{v_1, v_2, v_3, v_4\}$ is **linearly dependent**.

---

#### Example 2: Demonstrating Linear Independence in $\mathbb{R}^2$
Let $v_1 = (1,0)$ and $v_2 = (0,1) \in \mathbb{R}^2$.
Set up the vector equation:
$$\alpha_1 v_1 + \alpha_2 v_2 = \mathbf{0}$$

Substitute the vector components:
$$\alpha_1 (1,0) + \alpha_2 (0,1) = (0,0)$$
$$(\alpha_1, 0) + (0, \alpha_2) = (0,0)$$
$$(\alpha_1, \alpha_2) = (0,0)$$

Equating component by component:
$$\alpha_1 = 0 \quad \text{and} \quad \alpha_2 = 0$$

Since the **only** possible solution is the trivial solution $\alpha_1 = \alpha_2 = 0$, the set $\{v_1, v_2\}$ is **linearly independent**.

## 4. Fundamental Theorems & Lemmata

### 4.1 Lemma: Unique Representation in the Span of Independent Vectors

> **Lemma:** Let $V$ be a vector space over $F$. If $\{v_1, v_2, \dots, v_n\} \subseteq V$ is a set of linearly independent vectors, then every vector $v \in L(\{v_1, v_2, \dots, v_n\})$ has a **unique** expansion as a linear combination of these vectors.

#### Complete Step-by-Step Proof
1. Let $S = \{v_1, v_2, \dots, v_n\}$ be a set of linearly independent vectors, and let $v \in L(S)$.
2. By definition of $L(S)$, there exists at least one set of scalars $\alpha_1, \alpha_2, \dots, \alpha_n \in F$ such that:
   $$v = \alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n \quad \text{--- (Equation 1)}$$
3. **To prove uniqueness:** Assume $v$ can also be represented by a second set of scalars $\beta_1, \beta_2, \dots, \beta_n \in F$:
   $$v = \beta_1 v_1 + \beta_2 v_2 + \dots + \beta_n v_n \quad \text{--- (Equation 2)}$$
4. Subtract Equation 2 from Equation 1:
   $$v - v = (\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n) - (\beta_1 v_1 + \beta_2 v_2 + \dots + \beta_n v_n)$$
   $$\mathbf{0} = (\alpha_1 - \beta_1) v_1 + (\alpha_2 - \beta_2) v_2 + \dots + (\alpha_n - \beta_n) v_n$$
5. Because the set $\{v_1, v_2, \dots, v_n\}$ is **linearly independent**, the only way a linear combination of these vectors can equal the zero vector $\mathbf{0}$ is if every single scalar coefficient is zero:
   $$\alpha_1 - \beta_1 = 0 \implies \alpha_1 = \beta_1$$
   $$\alpha_2 - \beta_2 = 0 \implies \alpha_2 = \beta_2$$
   $$\vdots$$
   $$\alpha_n - \beta_n = 0 \implies \alpha_n = \beta_n$$
6. Since $\alpha_i = \beta_i$ for all $1 \le i \le n$, the representation is unique. $\blacksquare$

---

### 4.2 Theorem: Linear Dependence & Redundant Vectors

> **Theorem (Redundant Vector Theorem):** Let $\{v_1, v_2, \dots, v_n\}$ be an ordered collection of vectors in $V$. Then this set is either linearly independent, or there exists some vector $v_k$ (where $1 < k \le n$) that can be written as a linear combination of the preceding vectors $v_1, v_2, \dots, v_{k-1}$.

#### Complete Step-by-Step Proof
1. Consider the set $\{v_1, v_2, \dots, v_n\}$.
2. If the set is linearly independent, the condition is trivially satisfied.
3. If the set is **not** linearly independent, it is **linearly dependent**.
4. By definition of linear dependence, there exist scalars $\alpha_1, \alpha_2, \dots, \alpha_n \in F$, **not all zero**, such that:
   $$\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n = \mathbf{0} \quad \text{--- (Equation A)}$$
5. Let $k$ be the **largest index** such that $\alpha_k \neq 0$.
   That is, $\alpha_k \neq 0$, but $\alpha_{k+1} = 0, \alpha_{k+2} = 0, \dots, \alpha_n = 0$.
6. Substitute these zero scalars back into Equation A:
   $$\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_k v_k + 0 v_{k+1} + \dots + 0 v_n = \mathbf{0}$$
   $$\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_{k-1} v_{k-1} + \alpha_k v_k = \mathbf{0}$$
7. Isolate the term $\alpha_k v_k$ on the left side:
   $$\alpha_k v_k = -\alpha_1 v_1 - \alpha_2 v_2 - \dots - \alpha_{k-1} v_{k-1}$$
8. Because $\alpha_k \neq 0$, its multiplicative inverse $\alpha_k^{-1} \in F$ exists. Multiply both sides by $\alpha_k^{-1}$:
   $$v_k = \alpha_k^{-1} (-\alpha_1 v_1 - \alpha_2 v_2 - \dots - \alpha_{k-1} v_{k-1})$$
   $$v_k = \left(-\alpha_k^{-1} \alpha_1\right) v_1 + \left(-\alpha_k^{-1} \alpha_2\right) v_2 + \dots + \left(-\alpha_k^{-1} \alpha_{k-1}\right) v_{k-1}$$
9. Since $F$ is closed under field multiplication and addition, $(-\alpha_k^{-1} \alpha_i) \in F$ for every $1 \le i \le k-1$.
10. Thus, $v_k$ is expressed as an explicit linear combination of its preceding vectors $\{v_1, v_2, \dots, v_{k-1}\}$. $\blacksquare$

## 5. Summary & Comparison Table

| Property / Concept | Definition / Formula | Key Insight for Problem Solving |
| :--- | :--- | :--- |
| **Monotonicity of Span** | $S \subseteq T \implies L(S) \subseteq L(T)$ | Adding more vectors to a set can only expand or preserve its span, never shrink it. |
| **Span of Union** | $L(S \cup T) = L(S) + L(T)$ | The span of combined sets is equal to the sum of their individual spanned subspaces. |
| **Idempotency of Span** | $L(L(S)) = L(S)$ | Spanning an already spanned set creates no new vectors. |
| **Finite Dimensionality** | $\exists \text{ finite } S \subset V \text{ s.t. } L(S) = V$ | The vector space can be completely covered by linear combinations of a finite set of vectors. |
| **Linear Dependence** | $\sum a_i v_i = \mathbf{0}$ with at least one $a_i \neq 0$ | Contains redundant vector information; at least one vector lies in the span of the others. |
| **Linear Independence** | $\sum a_i v_i = \mathbf{0} \implies \text{all } a_i = 0$ | Zero redundancy; provides unique coordinates for every vector in its span. |
