# Basis Representation Uniqueness and Minimal Spanning Sets

## Overview & Core Concepts

In vector space theory, the concept of a **basis** serves as a coordinate system for abstract algebraic structures. A basis acts as an optimal generating set: it is large enough to span the entire vector space, yet small enough to avoid any redundant (linearly dependent) information. 

This unit establishes two foundational theorems regarding bases:
1. **Uniqueness of Coordinates:** Any vector in a vector space can be expressed as a linear combination of basis vectors in **exactly one way**.
2. **Minimal Spanning Set Equivalence:** A set of vectors that spans a vector space using the absolute minimum number of elements necessary is **guaranteed to be linearly independent**, and thus forms a basis.

---

## Uniqueness of Vector Representation in a Basis

### Theoretical Foundation
When a set of vectors $\mathcal{B} = \{a_1, a_2, \dots, a_r\}$ forms a basis for a vector space $V$ (such as $\mathbb{R}^n$), every vector $b \in V$ can be constructed via a linear combination of elements in $\mathcal{B}$. The fundamental property of a basis ensures that the coefficients (scalars) associated with each basis vector are **unique**.

### Theorem: Unique Representation Theorem
Let $V$ be a vector space over a field $F$ (e.g., $\mathbb{R}$), and let $S = \{a_1, a_2, \dots, a_r\}$ be a basis for $V$. Then every vector $b \in V$ can be uniquely expressed as a linear combination of the vectors in $S$.

---

### Step-by-Step Proof

#### Step 1: Assume Representation Non-Uniqueness (Proof by Contradiction/Direct Deduction)
Let $b \in V$. Suppose $b$ can be written in two different ways as a linear combination of the basis vectors $S = \{a_1, a_2, \dots, a_r\}$:

$$\text{Representation 1: } b = \alpha_1 a_1 + \alpha_2 a_2 + \dots + \alpha_r a_r$$

$$\text{Representation 2: } b = \beta_1 a_1 + \beta_2 a_2 + \dots + \beta_r a_r$$

where $\alpha_1, \alpha_2, \dots, \alpha_r \in F$ and $\beta_1, \beta_2, \dots, \beta_r \in F$ are scalars.

#### Step 2: Equate the Expressions and Subtract
Since both expressions equal the same vector $b$, set them equal to each other:

$$\alpha_1 a_1 + \alpha_2 a_2 + \dots + \alpha_r a_r = \beta_1 a_1 + \beta_2 a_2 + \dots + \beta_r a_r$$

Subtract the right-hand side from the left-hand side to gather like terms:

$$(\alpha_1 a_1 + \alpha_2 a_2 + \dots + \alpha_r a_r) - (\beta_1 a_1 + \beta_2 a_2 + \dots + \beta_r a_r) = \mathbf{0}$$

Group terms by matching vector components:

$$(\alpha_1 - \beta_1)a_1 + (\alpha_2 - \beta_2)a_2 + \dots + (\alpha_r - \beta_r)a_r = \mathbf{0}$$

#### Step 3: Apply the Linear Independence Property of a Basis
By definition, $S = \{a_1, a_2, \dots, a_r\}$ is a basis, which means its vectors are **linearly independent**.

The definition of linear independence states that the only linear combination of vectors that equals the zero vector $\mathbf{0}$ is the trivial combination where every scalar coefficient is identically zero.

Therefore, every scalar coefficient in the expression must equal zero:

$$\alpha_1 - \beta_1 = 0 \implies \alpha_1 = \beta_1$$
$$\alpha_2 - \beta_2 = 0 \implies \alpha_2 = \beta_2$$
$$\vdots$$
$$\alpha_r - \beta_r = 0 \implies \alpha_r = \beta_r$$

#### Conclusion
Since $\alpha_i = \beta_i$ for all $i \in \{1, 2, \dots, r\}$, the two representations are identical. Thus, the linear combination expressing $b$ in terms of the basis $S$ is unique.

$$\blacksquare$$

---

### Remark on Dimension
> **Fundamental Property:** If $V$ is a finite-dimensional vector space over a field $F$, then **any two bases** of $V$ contain the exact same number of elements. This fixed number of elements is defined as the **dimension** of the vector space, denoted $\dim(V)$.

## Minimal Spanning Sets and Basis Equivalence

### Definition: Minimal Spanning Set
A subset $S$ of a vector space $V$ is called a **minimal spanning set** if it satisfies two conditions:
1. **Spanning Condition:** $S$ spans $V$, meaning $L(S) = V$ (where $L(S)$ denotes the linear span of $S$).
2. **Minimality Condition:** Removing any element $v$ from $S$ results in a set that no longer spans $V$. That is, for any $v \in S$, $L(S \setminus \{v\}) \neq V$.

### Theorem: Minimal Spanning Set Forms a Basis
Let $V$ be a vector space over a field $F$. A minimal spanning set $S \subseteq V$ is a basis for $V$.

---

### Step-by-Step Proof

#### Step 1: Setup and Goal Identification
Let $S = \{v_1, v_2, \dots, v_n\}$ be a minimal spanning set for $V$. 
By definition of a minimal spanning set:
- $L(S) = V$

To prove that $S$ is a basis for $V$, we must show that $S$ fulfills the two conditions of a basis:
1. $S$ spans $V$ (already given).
2. $S$ is linearly independent.

Therefore, the proof reduces to showing that $S$ is **linearly independent**.

#### Step 2: Proof Strategy via Contradiction
Assume for the sake of contradiction that $S$ is **not** linearly independent (i.e., $S$ is linearly dependent).

By the **Redundant Vector Lemma** (Linear Dependence Theorem), if a set $S = \{v_1, v_2, \dots, v_n\}$ is linearly dependent, at least one vector $v_j$ (for some index $1 \le j \le n$) can be written as a linear combination of its preceding vectors $\{v_1, v_2, \dots, v_{j-1}\}$.

Thus, there exist scalars $\alpha_1, \alpha_2, \dots, \alpha_{j-1} \in F$ such that:

$$v_j = \alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_{j-1} v_{j-1}$$

#### Step 3: Evaluate Spanning Properties of the Reduced Set
Define the reduced set $S' = S \setminus \{v_j\} = \{v_1, v_2, \dots, v_{j-1}, v_{j+1}, \dots, v_n\}$.

Clearly, because $S' \subset S$, the span of $S'$ is contained within the span of $S$:

$$L(S') \subseteq L(S) = V$$

Now, we test if any arbitrary vector $x \in V$ can still be generated using only the elements of $S'$.

Since $S$ spans $V$, any $x \in V$ can be expressed as:

$$x = \beta_1 v_1 + \beta_2 v_2 + \dots + \beta_{j-1} v_{j-1} + \beta_j v_j + \beta_{j+1} v_{j+1} + \dots + \beta_n v_n$$

for some scalars $\beta_1, \beta_2, \dots, \beta_n \in F$.

#### Step 4: Substitute the Redundant Vector $v_j$
Substitute the linear combination expression for $v_j$ into the expansion for $x$:

$$x = \beta_1 v_1 + \dots + \beta_{j-1} v_{j-1} + \beta_j \left( \alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_{j-1} v_{j-1} \right) + \beta_{j+1} v_{j+1} + \dots + \beta_n v_n$$

Distribute $\beta_j$ and factor out the vectors $v_1, \dots, v_{j-1}$:

$$x = (\beta_1 + \beta_j \alpha_1) v_1 + (\beta_2 + \beta_j \alpha_2) v_2 + \dots + (\beta_{j-1} + \beta_j \alpha_{j-1}) v_{j-1} + \beta_{j+1} v_{j+1} + \dots + \beta_n v_n$$

#### Step 5: Derive the Contradiction
Notice that $x$ is now written entirely as a linear combination of vectors in $S' = \{v_1, v_2, \dots, v_{j-1}, v_{j+1}, \dots, v_n\}$.

This implies that:

$$x \in L(S') \implies V \subseteq L(S')$$

Since we already know $L(S') \subseteq V$, it follows that:

$$L(S') = L(S \setminus \{v_j\}) = V$$

This contradicts the initial assumption that $S$ is a **minimal** spanning set, as removing $v_j$ did not prevent the set from spanning $V$.

#### Step 6: Conclusion
The assumption that $S$ is linearly dependent leads to a logical contradiction. Therefore, $S$ must be **linearly independent**. 

Since $S$ spans $V$ and is linearly independent, $S$ is a **basis** for $V$.

$$\blacksquare$$

## Comparative Summary: Characterizations of a Basis

A basis can be understood through three equivalent characterizations:

| Characterization | Spanning Property | Linear Independence Property | Key Feature |
| :--- | :--- | :--- | :--- |
| **Standard Definition** | Spans $V$ ($L(S) = V$) | Linearly Independent | Balanced property set |
| **Minimal Spanning Set** | Spans $V$ ($L(S) = V$) | Minimal (removing any vector loses span) | Cannot be made smaller |
| **Maximal Linearly Independent Set** | Spans $V$ implicitly | Linearly Independent | Cannot be made larger without creating dependence |

## Step-by-Step Worked Examples

### Example 1: Verifying Uniqueness of Basis Representation

**Problem:**
Let $\mathcal{B} = \{v_1, v_2\} = \left\{ \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \begin{bmatrix} 1 \\ -1 \end{bmatrix} \right\}$ be a basis for $\mathbb{R}^2$. Find the unique coordinate representation of the vector $b = \begin{bmatrix} 5 \\ 1 \end{bmatrix}$ with respect to $\mathcal{B}$.

**Solution:**

#### Step 1: Set up the linear combination equation
We need to find unique scalars $\alpha_1, \alpha_2 \in \mathbb{R}$ such that:

$$b = \alpha_1 v_1 + \alpha_2 v_2$$

$$\begin{bmatrix} 5 \\ 1 \end{bmatrix} = \alpha_1 \begin{bmatrix} 1 \\ 1 \end{bmatrix} + \alpha_2 \begin{bmatrix} 1 \\ -1 \end{bmatrix}$$

#### Step 2: Convert to a system of linear equations
$$\begin{cases} \alpha_1 + \alpha_2 = 5 \\ \alpha_1 - \alpha_2 = 1 \end{cases}$$

#### Step 3: Solve the system
Add the two equations together:

$$(\alpha_1 + \alpha_2) + (\alpha_1 - \alpha_2) = 5 + 1 \implies 2\alpha_1 = 6 \implies \alpha_1 = 3$$

Substitute $\alpha_1 = 3$ back into the first equation:

$$3 + \alpha_2 = 5 \implies \alpha_2 = 2$$

#### Step 4: Verify uniqueness
The system of equations yields a single, unique solution $(\alpha_1, \alpha_2) = (3, 2)$.

$$b = 3 \begin{bmatrix} 1 \\ 1 \end{bmatrix} + 2 \begin{bmatrix} 1 \\ -1 \end{bmatrix} = \begin{bmatrix} 3 \\ 3 \end{bmatrix} + \begin{bmatrix} 2 \\ -2 \end{bmatrix} = \begin{bmatrix} 5 \\ 1 \end{bmatrix}$$

Thus, the representation of $b$ relative to basis $\mathcal{B}$ is uniquely given by the coordinates $\begin{bmatrix} 3 \\ 2 \end{bmatrix}$.

### Example 2: Testing Minimal Spanning Set Property

**Problem:**
Consider the set $S = \left\{ \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \begin{bmatrix} 2 \\ 3 \end{bmatrix} \right\}$ in $\mathbb{R}^2$. Show that $S$ spans $\mathbb{R}^2$, but is **not** a minimal spanning set. Find a minimal spanning set derived from $S$.

**Solution:**

#### Step 1: Check if $S$ spans $\mathbb{R}^2$
Let $x = \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} \in \mathbb{R}^2$. We want to solve:

$$\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = c_1 \begin{bmatrix} 1 \\ 0 \end{bmatrix} + c_2 \begin{bmatrix} 0 \\ 1 \end{bmatrix} + c_3 \begin{bmatrix} 2 \\ 3 \end{bmatrix}$$

Setting $c_3 = 0$ gives $c_1 = x_1$ and $c_2 = x_2$. Since a solution exists for any vector $x$, $L(S) = \mathbb{R}^2$.

#### Step 2: Test for minimality
Remove the third vector $v_3 = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$ to create the subset $S' = \left\{ \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \end{bmatrix} \right\}$.

Does $S'$ still span $\mathbb{R}^2$?
For any $\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} \in \mathbb{R}^2$:

$$\begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = x_1 \begin{bmatrix} 1 \\ 0 \end{bmatrix} + x_2 \begin{bmatrix} 0 \\ 1 \end{bmatrix}$$

Since $L(S') = \mathbb{R}^2$, removing $v_3$ did not reduce the span. Hence, $S$ is **not** a minimal spanning set.

#### Step 3: Confirm $S'$ is minimal
If we remove either remaining vector from $S'$:
- Removing $\begin{bmatrix} 1 \\ 0 \end{bmatrix}$ leaves $\left\{ \begin{bmatrix} 0 \\ 1 \end{bmatrix} \right\}$, which only spans the y-axis (cannot form vectors with $x_1 \neq 0$).
- Removing $\begin{bmatrix} 0 \\ 1 \end{bmatrix}$ leaves $\left\{ \begin{bmatrix} 1 \\ 0 \end{bmatrix} \right\}$, which only spans the x-axis (cannot form vectors with $x_2 \neq 0$).

Since removing any element from $S'$ destroys its capacity to span $\mathbb{R}^2$, $S'$ is a **minimal spanning set** (and therefore forms a basis for $\mathbb{R}^2$).
