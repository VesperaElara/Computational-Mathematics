# Linear Algebra: Maximal Linearly Independent Sets & Linear Independence Tests

## 1. Maximal Linearly Independent Sets

### 1.1 Intuitive Concept
To understand vector spaces, we need minimal sets of vectors that carry maximum structural information without redundancy. 

* A **linearly independent set** contains no redundant vectors (no vector can be written as a combination of others).
* A **maximal linearly independent set** is a linearly independent set expanded as far as possible within a vector space $V$. Adding *any* other vector from $V$ breaks its independence, forcing the new set to become linearly dependent.

---

### 1.2 Formal Definition
Let $V$ be a vector space over a field $F$. A subset $S \subseteq V$ is called a **maximal linearly independent set** if it satisfies two strict conditions:

1. **Linear Independence:** $S$ is a linearly independent set.
2. **Maximality Property:** For every vector $v \in V \setminus S$ (that is, any vector $v$ in $V$ not already in $S$), the set $S \cup \{v\}$ is linearly dependent.

---

### 1.3 Theorem & Proof: Maximal Independent Sets as Bases

#### Theorem
> Every maximal linearly independent set $S$ in a vector space $V$ is a basis for $V$.

#### Proof Strategy
Recall from prior definitions that a set $S \subseteq V$ is a **basis** for $V$ if and only if:
1. $S$ is linearly independent.
2. $S$ spans $V$ (i.e., $L(S) = V$).

Since $S$ is given to be a maximal linearly independent set, Condition 1 is satisfied by definition. We need only to prove that $S$ spans $V$—meaning every arbitrary vector $v \in V$ can be expressed as a linear combination of elements in $S$.

#### Step-by-Step Proof
Let $S = \{v_1, v_2, \dots, v_n\}$ be a maximal linearly independent set in $V$. Take an arbitrary vector $v \in V$.

1. **Case 1: $v \in S$**  
   If $v \in S$, say $v = v_1$, then $v$ is trivial to write as a linear combination:
   $$v = 1 \cdot v_1 + 0 \cdot v_2 + \dots + 0 \cdot v_n$$
   Hence, $v \in L(S)$.

2. **Case 2: $v \in V \setminus S$**  
   By the definition of maximality, adding $v$ to $S$ forms a set $S \cup \{v\} = \{v_1, v_2, \dots, v_n, v\}$ that is **linearly dependent**.

   By definition of linear dependence, there exist scalars $\alpha_1, \alpha_2, \dots, \alpha_n, \alpha \in F$, not all zero, such that:
   $$\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n + \alpha v = 0$$

3. **Determining the Scalar $\alpha$**  
   We analyze the scalar $\alpha$ attached to $v$ using proof by contradiction.
   
   Suppose $\alpha = 0$. Substituting $\alpha = 0$ into the equation yields:
   $$\alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n + 0 \cdot v = 0$$
   $$\implies \alpha_1 v_1 + \alpha_2 v_2 + \dots + \alpha_n v_n = 0$$

   Because $\{v_1, v_2, \dots, v_n\}$ is a linearly independent set, all coefficients must be zero:
   $$\alpha_1 = \alpha_2 = \dots = \alpha_n = 0$$

   This implies $\alpha_1 = \alpha_2 = \dots = \alpha_n = \alpha = 0$, which contradicts our premise that not all scalars are zero. Therefore, our assumption that $\alpha = 0$ is false.

   $$\implies \alpha \neq 0$$

4. **Expressing $v$ as a Linear Combination**  
   Since $\alpha \neq 0$, its multiplicative inverse $\alpha^{-1}$ exists in the field $F$. Rearranging the dependence equation:
   $$\alpha v = (-\alpha_1 v_1) + (-\alpha_2 v_2) + \dots + (-\alpha_n v_n)$$

   Multiplying both sides by $\alpha^{-1}$:
   $$v = (-\alpha_1 \alpha^{-1}) v_1 + (-\alpha_2 \alpha^{-1}) v_2 + \dots + (-\alpha_n \alpha^{-1}) v_n$$

   Since $(-\alpha_i \alpha^{-1}) \in F$ for all $1 \le i \le n$, $v$ is expressed as a linear combination of vectors in $S$.

5. **Conclusion**  
   Since an arbitrary $v \in V$ lies in $L(S)$, $S$ spans $V$ ($L(S) = V$). Combined with the linear independence of $S$, $S$ is a **basis** of $V$. $\blacksquare$

## 2. Testing Linear Independence in $\mathbb{R}^n$ Using Determinants

### 2.1 The Algebraic Method (Definition-Based)
To test whether a set of $n$ vectors $\{a_1, a_2, \dots, a_n\}$ in $\mathbb{R}^n$ is linearly independent, we start with the vector equation:
$$\lambda_1 a_1 + \lambda_2 a_2 + \dots + \lambda_n a_n = \mathbf{0}$$

This leads directly to a system of homogeneous linear equations:
$$A \boldsymbol{\lambda} = \mathbf{0}$$
where $A$ is the coefficient matrix containing the vectors as its rows (or columns) and $\boldsymbol{\lambda} = [\lambda_1, \lambda_2, \dots, \lambda_n]^T$.

* If the **only** solution is the trivial solution $\lambda_1 = \lambda_2 = \dots = \lambda_n = 0$, the vectors are **linearly independent**.
* If non-trivial solutions exist (at least one $\lambda_i \neq 0$), the vectors are **linearly dependent**.

---

### 2.2 The Determinant Criterion Theorem
For a set of $n$ vectors in an $n$-dimensional Euclidean space $\mathbb{R}^n$ (or $E^n$):

> A set of $n$ vectors in $\mathbb{R}^n$ forms a matrix $A$. The vectors are **linearly independent** if and only if the determinant of $A$ is non-zero:
> $$\det(A) \neq 0 \iff \text{Vectors are Linearly Independent}$$

| Matrix Determinant Condition | System Solution Type | Vector Status |
| :--- | :--- | :--- |
| $\det(A) \neq 0$ | Unique Trivial Solution ($\boldsymbol{\lambda} = \mathbf{0}$) | **Linearly Independent** |
| $\det(A) = 0$ | Infinitely Many Non-Trivial Solutions | **Linearly Dependent** |

---

### 2.3 Solved Example

#### Problem
Determine whether the vectors $a_1 = (4, 2, 1)$, $a_2 = (2, -6, -5)$, and $a_3 = (1, -2, 3)$ in $\mathbb{R}^3$ are linearly independent.

#### Step-by-Step Solution

**Step 1: Set up the linear combination equation.**  
Consider scalars $\lambda_1, \lambda_2, \lambda_3 \in \mathbb{R}$ such that:
$$\lambda_1 a_1 + \lambda_2 a_2 + \lambda_3 a_3 = \mathbf{0}$$

Substitute the given vector components:
$$\lambda_1 (4, 2, 1) + \lambda_2 (2, -6, -5) + \lambda_3 (1, -2, 3) = (0, 0, 0)$$

**Step 2: Construct the homogeneous system of linear equations.**  
Equating components position by position:
$$x\text{-component: } 4\lambda_1 + 2\lambda_2 + 1\lambda_3 = 0$$
$$y\text{-component: } 2\lambda_1 - 6\lambda_2 - 2\lambda_3 = 0$$
$$z\text{-component: } 1\lambda_1 - 5\lambda_2 + 3\lambda_3 = 0$$

**Step 3: Extract the matrix $A$ and calculate its determinant.**  
The coefficient matrix $A$ formed by placing vectors as row entries is:
$$A = \begin{bmatrix} 4 & 2 & 1 \\ 2 & -6 & -2 \\ 1 & -5 & 3 \end{bmatrix}$$

Calculate $\det(A) = |A|$ using cofactor expansion along Row 1:
$$|A| = 4 \begin{vmatrix} -6 & -2 \\ -5 & 3 \end{vmatrix} - 2 \begin{vmatrix} 2 & -2 \\ 1 & 3 \end{vmatrix} + 1 \begin{vmatrix} 2 & -6 \\ 1 & -5 \end{vmatrix}$$

Evaluate each $2 \times 2$ minor determinant:
1. First minor: $(-6)(3) - (-2)(-5) = -18 - 10 = -28$
2. Second minor: $(2)(3) - (-2)(1) = 6 + 2 = 8$
3. Third minor: $(2)(-5) - (-6)(1) = -10 + 6 = -4$

Substitute the minors back into the expansion:
$$|A| = 4(-28) - 2(8) + 1(-4)$$
$$|A| = -112 - 16 - 4 = -132$$

**Step 4: Interpret the result.**  
Since $|A| = -132 \neq 0$, the matrix $A$ is non-singular and invertible. This guarantees that the homogeneous system $A \boldsymbol{\lambda} = \mathbf{0}$ possesses **only** the trivial solution:
$$\lambda_1 = 0, \quad \lambda_2 = 0, \quad \lambda_3 = 0$$

**Conclusion:**  
The vectors $\{a_1, a_2, a_3\}$ are **linearly independent**.

## 3. Structural Rules & Dimensional Constraints

1. **Determinant Test Applicability:**  
   A set of vectors is linearly independent if $|A| \neq 0$, where $A$ is the matrix formed by placing the vectors as rows or columns. This test applies directly when the number of vectors equals the dimension of the space ($n$ vectors in $\mathbb{R}^n$).

2. **Maximum Capacity Theorem of $E^n$ / $\mathbb{R}^n$:**  
   The maximum number of linearly independent vectors in an $n$-dimensional Euclidean space $E^n$ ($\mathbb{R}^n$) is $n$. 

3. **Over-counting Dependency Rule:**  
   Any subset containing $n + 1$ or more vectors in $E^n$ is **always linearly dependent**. (For instance, 4 vectors in $\mathbb{R}^3$ are guaranteed to be linearly dependent without requiring any matrix calculations).
