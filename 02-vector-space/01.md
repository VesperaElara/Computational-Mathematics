# Section 5.2: Vector Spaces

To understand higher-level engineering concepts like vector spaces, we must build our foundation from the ground up. Abstract algebra provides the framework for these ideas. We will begin with the basic building blocks—**Groups** and **Fields**—before defining a **Vector Space**.

---

## 1. Mathematical Foundations: Groups & Fields

Before defining a vector space, we need to establish two algebraic structures: **Groups** and **Fields**.

### 1.1 Binary Operations

A **binary operation** on a non-empty set $G$ is a rule or mapping that takes any two elements from $G$ and combines them to produce another element within $G$.

Mathematically, a binary operation $*$ is a function:
$$* : G \times G \to G$$

If $a, b \in G$, then applying the binary operation yields an element $(a * b) \in G$. This property is known as **closure**.

---

### 1.2 Groups

A **group** is a non-empty set $G$ paired with a binary operation $*$ that obeys four fundamental rules called **axioms**. We denote a group as the pair $(G, *)$.

#### Axioms of a Group

For a set $G$ and operation $*$ to form a group, the following axioms must hold for all elements $a, b, c \in G$:

1. **Closure Axiom**: For every $a, b \in G$, the result $a * b \in G$.
2. **Associative Axiom**: The grouping of elements does not affect the result.
   $$(a * b) * c = a * (b * c)$$
3. **Identity Axiom**: There exists a unique identity element $e \in G$ such that operating on any element with $e$ leaves it unchanged.
   $$a * e = e * a = a$$
4. **Inverse Axiom**: For every element $a \in G$, there exists a unique inverse element $b \in G$ (often written as $a^{-1}$ or $-a$) such that their combination yields the identity element $e$.
   $$a * b = e = b * a$$

#### Special Types of Groups

* **Abelian Group**: A group $(G, *)$ is called **abelian** (or **commutative**) if the order of elements in the operation does not matter:
  $$a * b = b * a \quad \text{for all } a, b \in G$$
* **Commutative Multiplication**: Similarly, a group under multiplication $\cdot$ is commutative if $a \cdot b = b \cdot a$ for all $a, b \in G$.

#### Concrete Examples of Groups

1. **Integers under Addition $(\mathbb{Z}, +)$**:
   * **Set**: All integers $\{\dots, -2, -1, 0, 1, 2, \dots\}$.
   * **Operation**: Standard addition $(+)$.
   * **Associativity**: $(1 + 2) + 3 = 1 + (2 + 3) = 6$.
   * **Identity**: The integer $0$, since $a + 0 = 0 + a = a$.
   * **Inverse**: For any integer $a$, the additive inverse is $-a$, since $a + (-a) = 0$.
   * **Abelian Property**: $a + b = b + a$. Thus, $(\mathbb{Z}, +)$ is an **abelian group**.

2. **$2 \times 2$ Matrices under Matrix Addition**:
   * **Set**: All $2 \times 2$ matrices with real or complex entries.
   * **Operation**: Matrix addition.
   * **Identity**: The $2 \times 2$ zero matrix $\begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix}$.
   * **Inverse**: For any matrix $A$, its inverse is $-A$.
   * **Abelian Property**: $A + B = B + A$. This forms an **abelian group**.

---

### 1.3 Fields

A **field** is a set $F$ equipped with two binary operations: **addition** $(+)$ and **multiplication** $(\cdot)$. A field generalizes standard arithmetic operations, ensuring we can add, subtract, multiply, and divide (by non-zero elements).

#### Axioms of a Field

A non-empty set $F$ with operations $+$ and $\cdot$ is a **field** if it meets the following three conditions:

1. **Additive Abelian Group**: $(F, +)$ is an abelian group with an additive identity element denoted as $0$.
2. **Multiplicative Group of Non-Zero Elements**: The set of non-zero elements $F \setminus \{0\}$ forms a multiplicative group under $\cdot$ with a multiplicative identity element denoted as $1$.
3. **Distributive Laws**: Multiplication distributes over addition for all $a, b, c \in F$:
   $$a \cdot (b + c) = a \cdot b + a \cdot c$$
   $$(a + b) \cdot c = a \cdot c + b \cdot c$$

#### Concrete Examples of Fields

1. **Set of Real Numbers $(\mathbb{R})$**: Standard real numbers with conventional addition and multiplication form a field.
2. **Set of Complex Numbers $(\mathbb{C})$**: Complex numbers of the form $a + bi$ (where $i = \sqrt{-1}$) form a field under complex addition and multiplication.

> **Terminology Note**: Elements of a field $F$ are called **scalars**.

---

## 2. Vector Spaces

Now that we have defined fields, we can introduce the concept of a **Vector Space**.

A **vector space** $V$ over a field $F$ is a set of elements (called **vectors**) equipped with two operations:
1. **Vector Addition ($+$)**: Combining two vectors $v, w \in V$ to produce a vector $(v + w) \in V$.
2. **Scalar Multiplication**: Scaling a vector $v \in V$ by a scalar $\alpha \in F$ to yield a vector $(\alpha v) \in V$.


```
       +---------------------------------------+
       |             Vector Space V            |
       |   (Contains elements called vectors)   |
       +---------------------------------------+
                 /                   \
                /                     \
   Vector Addition (+)         Scalar Multiplication
  Combines two vectors         Scales vector by element
   (v + w) -> in V             from Field F (alpha * v) -> in V

```

---

### 2.1 Formal Definition and Axioms

A non-empty set $V$ is a **vector space** over a field $F$ (typically $\mathbb{R}$ or $\mathbb{C}$) if it satisfies two main properties comprising ten detailed rules:

#### Part 1: Vector Addition Axioms
The structure $(V, +)$ must be an **abelian group**. This means for all $u, v, w \in V$:

1. **Closure under Vector Addition**: $v + w \in V$.
2. **Commutativity**: $v + w = w + v$.
3. **Associativity**: $(u + v) + w = u + (v + w)$.
4. **Additive Identity**: There exists a unique zero vector $0 \in V$ such that for every $v \in V$:
   $$v + 0 = v$$
5. **Additive Inverse**: For every $v \in V$, there exists an inverse vector $-v \in V$ such that:
   $$v + (-v) = 0$$

#### Part 2: Scalar Multiplication Axioms
$V$ must be closed under scalar multiplication, and the operation must interact compatibility with field operations. For all scalars $\alpha, \beta \in F$ and all vectors $v, w \in V$:

6. **Closure under Scalar Multiplication**: $\alpha v \in V$.
7. **Distributivity over Vector Addition**:
   $$\alpha(v + w) = \alpha v + \alpha w$$
8. **Distributivity over Scalar Addition**:
   $$(\alpha + \beta)v = \alpha v + \beta v$$
9. **Compatibility of Scalar Multiplication**:
   $$\alpha(\beta v) = (\alpha \beta)v$$
10. **Identity Element of Scalar Multiplication**:
    $$1 \cdot v = v$$
    *(where $1$ is the multiplicative identity of the field $F$)*

---

### 2.2 Notation and Convention Rules

To maintain absolute clarity, we adhere to the following mathematical conventions throughout our study:

* **Field ($F$)**: The underlying scalar set (usually real numbers $\mathbb{R}$ or complex numbers $\mathbb{C}$).
* **Scalars**: Elements drawn from the field $F$, denoted by Greek letters ($\alpha, \beta, \gamma$) or lowercase standard letters ($a, b, c$).
* **Vectors**: Elements drawn from the vector space $V$, denoted by lowercase letters ($u, v, w$).
* **Operation Symbols**: 
  * The symbol $+$ represents either field addition or vector addition based on context.
  * The scalar $0$ represents the additive identity of the field, while $\mathbf{0}$ or $0_V$ denotes the zero vector of $V$.
  * Juxtaposition (placing symbols side-by-side like $\alpha v$ or $\alpha \beta$) denotes scalar-vector multiplication or scalar-scalar multiplication respectively.

# Section 5.2: Vector Spaces (Alternative Version)

To understand higher-level engineering concepts—such as signal processing, quantum mechanics, control systems, and structural mechanics—we must first establish a formal mathematical foundation for spaces and operations. 

This section introduces the foundational algebraic structures necessary to master Linear Algebra: **Groups**, **Fields**, and **Vector Spaces**.

---

## 1. Prerequisites & Fundamental Algebraic Structures

Before defining a Vector Space, we must understand two prerequisite structures: a **Group** and a **Field**. These structures provide the mathematical rules for addition and multiplication.

### 1.1 Binary Operations

> **Definition:** Given a non-empty set $G$, a **binary operation** on $G$ is a rule or mapping that takes any pair of elements from $G \times G$ and assigns them to a unique single element in $G$.
> 
> Mathematically:
> $$ * : G \times G \to G $$

When a binary operation is applied to elements within a set and the output remains within that same set, the set is said to be **closed** under that operation.

---

### 1.2 Groups

A group is one of the most fundamental algebraic structures in mathematics. It consists of a set paired with a single binary operation that follows four essential rules.

> **Definition:** A non-empty set $G$ together with a binary operation $*$ is called a **Group** (denoted as $(G, *)$) if it satisfies the following four axioms:
>
> 1. **Closure Axiom:** For all $a, b \in G$, the result $a * b \in G$.
> 2. **Associative Axiom:** For all $a, b, c \in G$,
>    $$ (a * b) * c = a * (b * c) $$
> 3. **Identity Axiom:** There exists a unique element $e \in G$ (called the *identity element*) such that for all $a \in G$:
>    $$ a * e = e * a = a $$
> 4. **Inverse Axiom:** For every element $a \in G$, there exists a corresponding element $b \in G$ (denoted as $a^{-1}$) such that:
>    $$ a * b = e = b * a $$

#### Abelian (Commutative) Groups

If a group satisfies an extra condition where the order of operations does not matter, it is called an **Abelian Group**.

> **Definition:** A group $(G, *)$ is called **Abelian** (or commutative) if:
> $$ a * b = b * a \quad \text{for all } a, b \in G $$

![Diagram: Structural Hierarchy of Groups and Abelian Groups](./images/group_hierarchy.png)
*Figure 1: Conceptual visualization showing that an Abelian group is a specialized group possessing the extra property of commutativity.*

#### Standard Examples of Groups

1. **Integers under Addition $(\mathbb{Z}, +)$:**
   * **Closure:** Sum of two integers is an integer.
   * **Associativity:** $(1 + 2) + 3 = 1 + (2 + 3) = 6$.
   * **Identity:** $e = 0$, since $a + 0 = a$.
   * **Inverse:** The inverse of $a$ is $-a$, since $a + (-a) = 0$.
   * **Commutative:** $a + b = b + a$. Thus, $(\mathbb{Z}, +)$ is an **Abelian group**.

2. **$2 \times 2$ Matrices under Addition:**
   The set of all $2 \times 2$ matrices with real or complex entries forms an **Abelian group** under matrix addition. The identity element is the $2 \times 2$ zero matrix:
   $$ O = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix} $$

---

### 1.3 Fields

While a group defines a set with **one** binary operation, a **Field** provides a framework for a set with **two** compatible binary operations: addition ($+$) and multiplication ($\cdot$).

> **Definition:** A non-empty set $F$ is a **Field** if it is equipped with two binary operations, $+ $ and $\cdot$, satisfying three master properties:
>
> 1. **Additive Abelian Group:** $(F, +)$ is an Abelian group with an additive identity denoted as $0$.
> 2. **Multiplicative Group of Non-Zero Elements:** $(F \setminus \{0\}, \cdot)$ forms a multiplicative group. That is, every non-zero element has a multiplicative inverse ($a^{-1}$ or $\frac{1}{a}$), and multiplication is associative and commutative with a multiplicative identity $1 \neq 0$.
> 3. **Distributive Laws:** Multiplication distributes over addition for all $a, b, c \in F$:
>    $$ a \cdot (b + c) = a \cdot b + a \cdot c $$
>    $$ (a + b) \cdot c = a \cdot c + b \cdot c $$

#### Standard Examples of Fields

* **Real Numbers $(\mathbb{R})$:** The set of real numbers with standard addition and multiplication forms a field.
* **Complex Numbers $(\mathbb{C})$:** The set of complex numbers forms a field under complex addition and multiplication.

*Note: In engineering linear algebra, the field $F$ is almost exclusively taken to be $\mathbb{R}$ or $\mathbb{C}$. The elements of a field $F$ are called **scalars**.*

---

## 2. Vector Spaces

Now that we have established the concepts of **Abelian Groups** and **Fields**, we can formally define a **Vector Space**.

A vector space is a set of elements (called **vectors**) that can be added together and scaled (multiplied by elements of a field, called **scalars**), adhering to strict structural rules.

![Diagram: Interaction Between Field (Scalars) and Vector Space (Vectors)](./images/vector_space_interaction.png)

---

### 2.1 Formal Definition of a Vector Space

> **Definition:** A non-empty set $V$ is called a **Vector Space over a Field $F$** (written as $V(F)$) if it is equipped with two operations:
> 1. **Vector Addition ($+$):** $V \times V \to V$
> 2. **Scalar Multiplication ($\cdot$):** $F \times V \to V$
>
> such that the following 10 fundamental axioms hold:

#### Part A: Vector Addition Axioms
For all vectors $u, v, w \in V$:

1. **Closure under Vector Addition:** 
   $$ u + v \in V $$
2. **Associativity of Vector Addition:** 
   $$ (u + v) + w = u + (v + w) $$
3. **Existence of Additive Identity:** 
   There exists a zero vector $\mathbf{0} \in V$ such that:
   $$ v + \mathbf{0} = \mathbf{0} + v = v \quad \forall v \in V $$
4. **Existence of Additive Inverse:** 
   For every $v \in V$, there exists an element $-v \in V$ such that:
   $$ v + (-v) = \mathbf{0} $$
5. **Commutativity of Vector Addition:** 
   $$ u + v = v + u $$

*(In short: $(V, +)$ must be an **Abelian Group**).*

---

#### Part B: Scalar Multiplication Axioms
For all scalars $\alpha, \beta \in F$ and vectors $v, w \in V$:

6. **Closure under Scalar Multiplication:** 
   $$ \alpha v \in V $$
7. **Distributivity of Scalar Addition:** 
   $$ (\alpha + \beta)v = \alpha v + \beta v $$
8. **Distributivity of Vector Addition:** 
   $$ \alpha(v + w) = \alpha v + \alpha w $$
9. **Compatibility/Associativity of Scalar Multiplication:** 
   $$ \alpha(\beta v) = (\alpha \beta)v $$
10. **Scalar Identity Element:** 
    For $1 \in F$ (the multiplicative identity of the field):
    $$ 1 \cdot v = v $$

---

## 3. Step-by-Step Practical Problem Solving

### Example Problem 1: Verifying a Vector Space Axiom

**Problem Statement:**  
Let $V = \mathbb{R}^2$ be the set of all 2D real vectors $\begin{pmatrix} x_1 \\ x_2 \end{pmatrix}$ with $x_1, x_2 \in \mathbb{R}$. Define addition standardly and scalar multiplication as:
$$ \alpha \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} \alpha x_1 \\ \alpha x_2 \end{pmatrix} $$
Verify that the scalar distributivity over vector addition axiom $\alpha(v + w) = \alpha v + \alpha w$ holds for $v = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}, w = \begin{pmatrix} y_1 \\ y_2 \end{pmatrix} \in \mathbb{R}^2$ and $\alpha \in \mathbb{R}$.

---

#### Step-by-Step Solution:

1. **Evaluate the Left-Hand Side (LHS):**
   First, perform the vector addition inside the parentheses:
   $$ v + w = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} + \begin{pmatrix} y_1 \\ y_2 \end{pmatrix} = \begin{pmatrix} x_1 + y_1 \\ x_2 + y_2 \end{pmatrix} $$
   
   Next, multiply by the scalar $\alpha$:
   $$ \text{LHS} = \alpha(v + w) = \alpha \begin{pmatrix} x_1 + y_1 \\ x_2 + y_2 \end{pmatrix} = \begin{pmatrix} \alpha(x_1 + y_1) \\ \alpha(x_2 + y_2) \end{pmatrix} $$

   Using the distributive law of real numbers inside the vector components:
   $$ \text{LHS} = \begin{pmatrix} \alpha x_1 + \alpha y_1 \\ \alpha x_2 + \alpha y_2 \end{pmatrix} $$

2. **Evaluate the Right-Hand Side (RHS):**
   Apply scalar multiplication to each vector individually:
   $$ \alpha v = \alpha \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} \alpha x_1 \\ \alpha x_2 \end{pmatrix} $$
   $$ \alpha w = \alpha \begin{pmatrix} y_1 \\ y_2 \end{pmatrix} = \begin{pmatrix} \alpha y_1 \\ \alpha y_2 \end{pmatrix} $$

   Now perform vector addition on the results:
   $$ \text{RHS} = \alpha v + \alpha w = \begin{pmatrix} \alpha x_1 \\ \alpha x_2 \end{pmatrix} + \begin{pmatrix} \alpha y_1 \\ \alpha y_2 \end{pmatrix} = \begin{pmatrix} \alpha x_1 + \alpha y_1 \\ \alpha x_2 + \alpha y_2 \end{pmatrix} $$

3. **Conclusion:**
   $$ \text{LHS} = \text{RHS} $$
   The axiom $\alpha(v + w) = \alpha v + \alpha w$ is satisfied.
