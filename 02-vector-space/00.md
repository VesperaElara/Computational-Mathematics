# Foundation: Sets and Functions 
*(Prerequisite for Vector Spaces and Inner-Product Spaces)*

Before we can build complex mathematical structures like "Vector Spaces," we must first understand the fundamental language of mathematics: **Sets** and **Functions**. Think of sets as the basic building blocks (like Lego bricks), and functions as the rules for how we can connect them. 

---

## 1. The Basics of Sets

### What is a Set?
A **set** is simply a well-defined collection of distinct objects. By "well-defined," we mean that there is no ambiguity—you can look at any object and say with 100% certainty whether it is inside the collection or not.

The objects inside a set are called its **elements** or **members**. 

*   If an object $a$ is inside a set $A$, we write **$a \in A$** (read as "$a$ belongs to $A$").
*   If an object $x$ is *not* inside $A$, we write **$x \notin A$** (read as "$x$ does not belong to $A$").

### How Do We Write Sets?
There are two main ways to write down a set:
1.  **Roster Method (Listing):** We list every element inside curly braces. 
    *   *Example:* $S = \{1, 2, 3\}$
2.  **Set-Builder Notation (Descriptive):** We state a rule or property that elements must satisfy to get into the set.
    *   *Example:* Let $E$ be the set of all even positive integers. We write this as:
        $$E = \{x \mid x \text{ is an even integer and } x > 0\}$$
        *(Read as: "The set of all $x$ such that $x$ is an even integer and $x$ is greater than zero.")*
    *   Using this set, $2 \in E$ is true, but $-3 \notin E$ is also true.

## 2. The "VIP" Sets in Mathematics
There are a few incredibly important sets of numbers that you will see everywhere in engineering. We use special bold/hollow letters for them:

*   **$\mathbb{N}$ (Natural Numbers):** The counting numbers. $\mathbb{N} = \{1, 2, 3, \dots\}$
*   **$\mathbb{Z}$ (Integers):** Whole numbers, including zero and negatives. $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$
*   **$\mathbb{Q}$ (Rational Numbers):** Fractions. Any number that can be written as $p/q$, where $p$ and $q$ are integers and the denominator $q \neq 0$.
*   **$\mathbb{R}$ (Real Numbers):** Every number on the continuous number line (includes integers, fractions, and irrational numbers like $\pi$ and $\sqrt{2}$).
*   **$\mathbb{C}$ (Complex Numbers):** Numbers that include an imaginary part (e.g., $a + bi$).

---

## 3. Comparing Sets (Subsets and Equality)

How do sets relate to one another? 

*   **Subset ($\subseteq$):** Set $A$ is a subset of Set $B$ (written $A \subseteq B$) if *every* element in $A$ is also found inside $B$. 
    *   *Hierarchy of numbers:* $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$. (Every natural number is an integer, every integer is a fraction like $5/1$, etc.)
*   **Equal Sets ($=$):** Two sets are perfectly equal ($A = B$) if they contain the exact same elements. Mathematically, this means $A \subseteq B$ AND $B \subseteq A$.
*   **Proper Subset ($\subset$):** If $A$ is a subset of $B$, but $A$ is *not* equal to $B$ (meaning $B$ has some extra stuff), then $A$ is a proper subset of $B$.
*   **Null Set / Empty Set ($\phi$):** A set with absolutely nothing inside it. It is denoted by the Greek letter $\phi$ (phi) or simply $\{\}$. *Note: The empty set is considered a subset of every set.*

## 4. Set Operations
Just as we can add or multiply numbers, we can combine sets using specific operations. Let's assume we are pulling our elements from a massive master set called the **Universal Set ($U$)**.

### I. Union ($A \cup B$)
The union of two sets is a new set containing everything that is in $A$, or in $B$, or in both. 
$$A \cup B = \{x \mid x \in A \text{ or } x \in B\}$$

### II. Intersection ($A \cap B$)
The intersection is a new set containing ONLY the items that both $A$ and $B$ share in common.
$$A \cap B = \{x \mid x \in A \text{ and } x \in B\}$$

### III. Difference / Relative Complement ($B \setminus A$ or $B - A$)
The difference of sets is what you get when you start with $B$ and remove anything that is also in $A$. 
$$B \setminus A = \{x \mid x \in B \text{ and } x \notin A\}$$

### IV. Absolute Complement ($A'$)
The complement of $A$ is absolutely everything in the Universal Set ($U$) that is *not* in $A$.
$$A' = \{x \in U \mid x \notin A\}$$

**Example of Set Operations:**
Imagine our Universal set $U = \mathbb{R}$ (all real numbers).
Let $A = \{x \in \mathbb{R} \mid 0 < x \le 3\}$ (numbers from 0 to 3, including 3)
Let $B = \{x \in \mathbb{R} \mid 2 \le x < 4\}$ (numbers from 2 to 4, including 2)
*   $A \cap B = \{x \in \mathbb{R} \mid 2 \le x \le 3\}$ *(The overlapping region)*
*   $A \cup B = \{x \in \mathbb{R} \mid 0 < x < 4\}$ *(The combined region)*
*   $A \setminus B = \{x \in \mathbb{R} \mid 0 < x < 2\}$ *(A, but with the B overlap removed)*

### V. Multiple / Infinite Operations
We can union or intersect many sets at once, not just two. If we have a collection of sets $A_i$ (where $i$ is an index like 1, 2, 3...), we write:
*   **Mass Union:** $\bigcup_{i \in I} A_i = \{a \mid a \in A_i \text{ for some } i\}$
*   **Mass Intersection:** $\bigcap_{i \in I} A_i = \{a \mid a \in A_i \text{ for all } i\}$

**Mutually Disjoint Sets:** If you have a group of sets where no two sets share *any* common elements (their intersection is the empty set $\phi$), they are called mutually disjoint.

### VI. Symmetric Difference ($A \Delta B$ or $A \oplus B$)
This is an exclusive operation. It contains elements that are in $A$ or in $B$, but **not both**.
$$A \oplus B = (A - B) \cup (B - A)$$
*Example:* If $A = \{1, 2, 3, 4\}$ and $B = \{1, 2, 5, 7\}$, then $A \oplus B = \{3, 4, 5, 7\}$. (Notice 1 and 2 are removed because they are in both).

## 5. Laws of Set Operations

Sets behave mathematically according to specific laws. Let $U$ be the Universal set and $\phi$ be the empty set.

| Law Name | Properties |
| :--- | :--- |
| **Commutative** | $A \cup B = B \cup A$ <br> $A \cap B = B \cap A$ |
| **Associative** | $A \cup (B \cup C) = (A \cup B) \cup C$ <br> $A \cap (B \cap C) = (A \cap B) \cap C$ |
| **Distributive** | $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ <br> $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ |
| **Idempotent** | $A \cup A = A$ <br> $A \cap A = A$ |
| **Double Complement**| $(A')' = A$ |
| **Identity/Universal**| $A \cup A' = U$ *(Everything)* <br> $A \cap A' = \phi$ *(Nothing)* <br> $\phi' = U$ <br> $U' = \phi$ <br> $A \cup \phi = A$ <br> $A \cap U = A$ |
| **De Morgan's Laws** | $(A \cup B)' = A' \cap B'$ *(The complement of a union is the intersection of complements)* <br> $(A \cap B)' = A' \cup B'$ *(The complement of an intersection is the union of complements)* |

### Size of Sets (Cardinality)
The number of elements in a set $A$ is denoted by $|A|$.
1.  $|P \cup Q| \le |P| + |Q|$ *(It's only equal if they share no elements).*
2.  $|P \cap Q| \le \min(|P|, |Q|)$ *(The intersection can't be bigger than the smallest set).*
3.  $|P \oplus Q| = |P| + |Q| - 2|P \cap Q|$ *(Add both sizes, then subtract the overlap twice because you counted it twice, and symmetric difference wants zero overlaps).*

## 6. The Cartesian Product

How do we mathematically pair up elements from two different sets? We use the **Cartesian Product**.

If $S$ and $T$ are two sets, their Cartesian product $S \times T$ is the set of all possible **ordered pairs** $(s, t)$ where the first item comes from $S$ and the second comes from $T$.
$$S \times T = \{(s, t) \mid s \in S \text{ and } t \in T\}$$

*Note: Order matters! $(s, t)$ is not the same as $(t, s)$. Therefore, $S \times T \neq T \times S$.*

**Example:**
Let $X = \{a, b\}$ and $Y = \{x, y\}$.
$X \times Y = \{(a, x), (a, y), (b, x), (b, y)\}$
$Y \times X = \{(x, a), (x, b), (y, a), (y, b)\}$

We can extend this to $n$ sets ($S_1 \times S_2 \times \dots \times S_n$) to create **ordered n-tuples**: $(s_1, s_2, \dots, s_n)$.

## 7. Functions: The Mathematical Machines

In basic terms, a **function** is a machine. You feed it an input, and it spits out exactly one output. 

Rigorously, a function $f$ from Set $S$ to Set $T$ (written **$f: S \to T$**) is a special type of subset of the Cartesian product $S \times T$. It must satisfy two strict rules:
1.  Every element $s$ in $S$ must have a corresponding element $t$ in $T$. (Every input must have an output).
2.  If an input $s$ goes to $t$, and $s$ also goes to $u$, then $t$ must equal $u$. (One input cannot yield two different outputs).

**Terminology:**
*   **Domain ($S$):** The set of all possible valid inputs.
*   **Codomain ($T$):** The "target" set that contains all possible outputs.
*   **Image of $s$:** If $f(s) = t$, $t$ is the image.
*   **Preimage of $t$:** The input $s$ that created $t$.
*   **Range (or Image of $f$):** The actual subset of the Codomain that gets hit by inputs. (Not every element in the target set necessarily gets mapped to).

**Example:** 
Let $f: \mathbb{N} \to \mathbb{N}$ defined by $f(x) = x \pmod 3$ (the remainder when dividing by 3).
*   Domain = $\mathbb{N} = \{1, 2, 3, 4, 5 \dots\}$
*   Codomain = $\mathbb{N} = \{1, 2, 3, \dots\}$
*   Range = $\{0, 1, 2\}$ *(Because those are the only possible remainders).*

## 8. Types of Functions

Depending on how inputs map to outputs, functions get special classifications.

### I. Injective (One-to-One)
A function is **one-to-one** if every output has exactly *one* unique input. No two different inputs map to the same output.
*   *Mathematical condition:* $f(s_1) = f(s_2) \implies s_1 = s_2$.

### II. Surjective (Onto)
A function is **onto** if every single element in the target Codomain is "hit" by at least one input. The Range perfectly equals the Codomain.
*   *Mathematical condition:* For every $t \in T$, there is some $s \in S$ such that $f(s) = t$.

### III. Bijective
A function is a **bijection** if it is BOTH one-to-one and onto. This is the gold standard for mapping because it means there is a perfect 1-to-1 pairing between every element in the domain and codomain.

## 9. Composition of Functions (Chaining Machines)

What happens if you take the output of one function and immediately shove it in as the input to a second function? This is called **Composition**.

If we have $g: S \to T$ and $f: T \to U$, the composition function **$f \circ g$** (read as "$f$ of $g$") is a direct route from $S$ to $U$. 
$$(f \circ g)(s) = f(g(s))$$
*Note: We apply the function on the RIGHT first ($g$), and feed its result into the function on the LEFT ($f$).*

### Solved Example: Computing Compositions
**Problem:** Let $f: \mathbb{R} \to \mathbb{R}$ and $g: \mathbb{R} \to \mathbb{R}$. We are given the functions $f(x) = x^2 - 2$ and $g(x) = x + 4$. Find the formulas for $(g \circ f)$ and $(f \circ g)$.

**Solution:**

**Part 1: Find $(g \circ f)(x)$**
This means we plug $f(x)$ into $g(x)$.
1.  Start with the outer function: $(g \circ f)(x) = g(f(x))$
2.  Substitute the inner function $f(x)$: $= g(x^2 - 2)$
3.  Look at the rule for $g$. The rule is "take the input and add $4$". Our input is now $(x^2 - 2)$.
4.  Apply the rule: $= (x^2 - 2) + 4$
5.  Simplify: **$= x^2 + 2$**

**Part 2: Find $(f \circ g)(x)$**
This means we plug $g(x)$ into $f(x)$.
1.  Start with the outer function: $(f \circ g)(x) = f(g(x))$
2.  Substitute the inner function $g(x)$: $= f(x + 4)$
3.  Look at the rule for $f$. The rule is "take the input, square it, and subtract $2$". Our input is now $(x + 4)$.
4.  Apply the rule: $= (x + 4)^2 - 2$
5.  Expand the squared binomial: $= (x^2 + 8x + 16) - 2$
6.  Simplify: **$= x^2 + 8x + 14$**

*Key Takeaway from this example: Notice that $(g \circ f) \neq (f \circ g)$. The order in which you chain mathematical machines changes the final outcome!*
